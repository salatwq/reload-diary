# My School Reload

Школьный дневник для «Моей школы» (Госуслуги) в стиле меню паузы Persona 3 Reload. Kotlin + Jetpack Compose.

- Сборка: автоматически на GitHub Actions при каждом push в `main`, APK — в разделе Releases.
- Первый запуск: демо-режим. Реальные данные: Аккаунт → «Войти через Госуслуги» → войти → «Я ВОШЁЛ» → «ЗАКРЫТЬ» → «ОБНОВИТЬ ДАННЫЕ».
- Подробности устройства и правила работы — в `CLAUDE.md`.
