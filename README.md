# Дневник Reload — Android (Kotlin + Jetpack Compose)

Электронный дневник для de.edu.orb.ru в стилизации под синее меню паузы (оригинальная графика, без ассетов игры).

## Сборка
1. Android Studio (Ladybug или новее) → File → Open → папка проекта.
2. Дождаться Gradle Sync (AGP 8.9.1, Kotlin 2.1.20, compileSdk/targetSdk 36 — при предложении студии версии можно обновить).
3. Run ▶ на телефоне или эмуляторе. APK: Build → Build APK(s).

## Первый запуск
Приложение стартует в ДЕМО-режиме (можно оценить интерфейс).
Реальные данные: Главное меню → Аккаунт → «Войти через Госуслуги» → в браузере войти →
«Я ВОШЁЛ» → открыть в дневнике страницу расписания → «ЭТО РАСПИСАНИЕ» (то же для оценок и ДЗ) → Аккаунт → «Обновить».

## Разбор страниц
`data/Scraper.kt` читает все `<table>` со страницы и разбирает их эвристиками. Если данные не распознаются —
в браузере нажмите «КОПИРОВАТЬ HTML» и пришлите страницу (предварительно удалив личные данные), парсер будет подогнан.
